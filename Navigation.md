# Homelab Repository Navigation

## How to Find What You Need

1. **Start at the root README** – Overview of purpose, ownership, and top‑level folder map.
2. **Indexes/** – Centralised navigation files generated by CI:
   - `ServiceCatalog.md` – High‑level service list.
   - `ServiceIndex.md` – Detailed service folder index.
   - `StandardsIndex.md` – List of all standards.
   - `DocumentationIndex.md` – Documentation map.
   - `TemplateIndex.md` – Template catalogue.
   - `ADRIndex.md` – Architecture Decision Records index.
3. **Folder Structure** – Follow the deterministic hierarchy:
   - `Architecture/` (standards, decisions, diagrams, AI, hardware, networking)
   - `Services/` (individual service directories)
   - `Templates/` (document and config templates)
   - `Assets/` (images, icons, diagrams, etc.)
   - `Validation/` (audit reports, benchmarks, compliance)
   - `.github/workflows/` – CI pipelines (future).
4. **Cross‑References** – Use `[[Document Title]]` markdown links for intra‑repo navigation.
5. **Future Navigation Enhancements** – Automated index regeneration, AI‑driven semantic search, and Hermes/Honcho integration will keep navigation up‑to‑date.
