This directory is the intended home for the user's **original ChatGPT
conversation history**, organized by topic. It is **historical source
material**, not KORA memory and not the curated archive.

## Relationship to the Personal Knowledge Archive

```text
ChatGPT_History/          = raw conversations (historical evidence, preserved)
Personal_Knowledge_Archive.md = curated knowledge layer (what KORA should know)
```

Raw conversations are **not** converted wholesale into Honcho/Chroma. A
separately approved Phase 17 ingestion step will curate them into the archive
and later route archive content to Chroma (searchable corpus) and Honcho
(selected durable memory).
