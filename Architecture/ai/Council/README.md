# Council

The Council is KORA’s **collective reasoning framework**: specialized members deliberate under coordinated facilitation and return a coherent recommendation to the user.

**Platform architecture (KORA / Brainiac):** [../KORA.md](../KORA.md)

KORA is a Council member (Conductor / Chair / First Among Equals)—not a separate authority above the Council, and not a manager of members as employees or sub-agents.
