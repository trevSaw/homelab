# Council Schemas (Conceptual)

Conceptual data shapes for Council sessions.  
**Not** an implementation schema language lock-in. YAML examples are illustrative.

| Schema | Purpose |
| --- | --- |
| [request.yaml](request.yaml) | Classified request + selection intent |
| [member_response.yaml](member_response.yaml) | Single member contribution |
| [deliberation.yaml](deliberation.yaml) | Session deliberation state |
| [recommendation.yaml](recommendation.yaml) | Final user-facing recommendation |

Authoritative behavior: `../Dynamics.md`, `../Selection.md`, `../Voting.md`, `../Deliberation.md`.
