# Memory

Memory architecture for KORA: persistent knowledge of past interactions and decisions.

## Role in the KORA architecture

Memory is a **subsystem of KORA**, not a Council member and not a separate AI identity.

| Memory owns | Memory does not own |
| --- | --- |
| Continuity across sessions | Council reasoning (see `Council/Dynamics.md`) |
| Traces of decisions, preferences, and outcomes | Live environment truth (see `MCP.md` / tools) |
| Inputs that help historical and pattern-aware deliberation | Model serving topology (see `Models.md`) |

Canonical platform definition: `KORA.md`.  
Detailed memory / knowledge design: Phase 13.2 and Phase 13.5.
