# Architecture Decision Records (ADRs)

This directory stores Architecture Decision Records that capture significant design decisions for the homelab repository.

* Each ADR is a Markdown file named `ADR-####-short-description.md`.
* An ADR should include the required sections described in `ADRTemplate.md`.
* All ADRs are listed in `../Indexes/ADRIndex.md`.

The directory may contain additional helper scripts or resources required by specific ADRs.
