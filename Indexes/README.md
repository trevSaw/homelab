# Indexes

Centralised index files for rapid navigation of the homelab repository.

## Index Files (to be generated)
- **ServiceCatalog.md** – High‑level catalogue of all services.
- **ServiceIndex.md** – Detailed list of service folders with descriptions.
- **StandardsIndex.md** – List of all standards under `Architecture/standards/`.
- **DocumentationIndex.md** – Index of all documentation artefacts.
- **TemplateIndex.md** – Index of available templates.
- **ADRIndex.md** – Global ADR index.
- **ResearchIndex.md** – Placeholder for future research links.

These files will be auto‑generated by CI pipelines using the front‑matter metadata.
