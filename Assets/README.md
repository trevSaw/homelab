# Assets

Repository‑wide assets used by services, documentation, and diagrams.

## Sub‑folders
- **images/** – Screenshots, UI mock‑ups.
- **icons/** – Service icons and UI icons.
- **logos/** – Branding logos for services.
- **diagrams/** – Architecture and network diagrams (draw.io, PlantUML).
- **branding/** – Color palettes, typography, style guides.
- **screenshots/** – Visual documentation for runbooks.
- **templates/** – Asset templates (e.g., SVG stencils).

All assets should be referenced via relative paths in markdown files and should include a small header comment describing their purpose.
