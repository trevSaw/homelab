# Templates

Standardized templates for documents, services, runbooks, and configuration files used across the homelab repository.

## Available Templates
- **ComposeTemplate.yaml** – Docker Compose starter file.
- **ReadmeTemplate.md** – README scaffold with metadata front‑matter.
- **ServiceTemplate.md** – Service documentation template.
- **RunbookTemplate.md** – Operational runbook template.
- **ADRTemplate.md** – Architecture Decision Record skeleton.
- **ChecklistTemplate.md** – Generic checklist format.

All templates reference the `MetadataStandard` for required front‑matter fields.
